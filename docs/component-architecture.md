## Основні рішення

Компоненти було розділено за відповідальністю. Сторінкові компоненти поєднують дані та окремі блоки інтерфейсу, а предметні компоненти відповідають за відображення інформації про номери.

Компонент Section використовується повторно для різних секцій і отримує вкладений вміст через children.

Компонент RoomStatus використовується в різних частинах застосунку, що дозволяє не дублювати правило відображення статусу номера.

Для оформлення застосунку використовуються власні CSS-стилі без підключення React Bootstrap.

## Карта стану ЛР 2.1

| Значення | Призначення | Початкове значення | Власник | Споживачі | Скидання |
|---|---|---|---|---|---|
| detailsOpen | Показ або приховування опису номера | false | RoomCard | конкретна RoomCard | при повторному натисканні або демонтуванні картки |
| query | Пошук номера за назвою | '' | HomePage | фільтри, список номерів | кнопка «Скинути фільтри» |
| availableOnly | Показ лише доступних номерів | false | HomePage | фільтри, список номерів | кнопка «Скинути фільтри» |
| selectedId | Ідентифікатор вибраного номера | null | спочатку App, пізніше RoomSelectionProvider | каталог і секція бронювання | скасування вибору |
| draft | Чернетка бронювання | порожні поля | BookingPage | форма та підсумок | очищення, зміна номера або скасування вибору |

### Похідні значення

- visibleRooms — обчислюється з масиву rooms, query та availableOnly; окремий useState не потрібний.
- selectedRoom — знаходиться за selectedId у масиві rooms; окремий useState не потрібний.
- кількість видимих номерів — обчислюється з visibleRooms.length.


## Маршрутизація та навігація

Для маршрутизації вебзастосунку використовується React Router.

### Структура маршрутів

- `/` — головна сторінка.
- `/rooms` — каталог номерів із фільтрами.
- `/rooms/:roomId` — детальна інформація про номер.
- `/bookings` — список демонстраційних бронювань.
- `/bookings/new?roomId=1` — створення бронювання для вибраного номера.
- `/bookings/:bookingId/edit` — редагування бронювання.
- `*` — оброблення невідомих маршрутів.

### Основні компоненти

- `App.jsx` — визначає маршрути та вкладені сторінки.
- `AppLayout.jsx` — спільний макет із шапкою, основним вмістом і футером.
- `MainNav.jsx` — основна навігація з використанням `NavLink`.
- `BookingsLayout.jsx` — вкладений макет розділу бронювань.
- `RoomDetailsPage.jsx` — відображає інформацію про номер за параметром `roomId`.
- `BookingsPage.jsx` — відображає список бронювань.
- `BookingCreatePage.jsx` — обробляє створення бронювання.
- `BookingEditPage.jsx` — завантажує демонстраційні дані для редагування.

### Параметри URL

Пошук і фільтр доступності зберігаються в рядку запиту URL:
- `q` — пошуковий запит за назвою номера.
- `available=1` — показувати лише доступні номери.
- `roomId` — ідентифікатор номера для створення бронювання.
- `roomId` у маршруті деталей і `bookingId` у маршруті редагування визначають відповідні записи.

### Стан застосунку

`RoomSelectionProvider` забезпечує спільний стан вибраного номера. Він розташований у спільному макеті, щоб стан зберігався під час навігації між вкладеними сторінками.

Демонстраційні бронювання зберігаються в `src/data/bookings.js`. Дані не записуються до бази даних, а зміни форми редагування поки не зберігаються в масиві.
