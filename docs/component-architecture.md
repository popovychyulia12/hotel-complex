# Архітектура компонентів

## Ієрархія компонентів

App
└── AppLayout
    ├── SiteHeader
    │   └── MainNav
    ├── HomePage
    │   ├── Section
    │   └── RoomList
    │       └── RoomCard
    │           └── RoomStatus
    └── BookingPage
        ├── Section
        ├── RoomStatus
        └── BookingFormPreview
            ├── FormField
            └── AppButton

## Контракти компонентів

| Компонент | Props | Призначення |
|---|---|---|
| AppLayout | title, links, children | Формує спільну структуру сторінки |
| SiteHeader | title, links | Відображає назву сайту та навігацію |
| MainNav | links | Відображає список навігаційних посилань |
| Section | id, title, children | Формує повторно використовувану секцію |
| RoomList | rooms | Відображає список номерів |
| RoomCard | room | Відображає інформацію про один номер |
| RoomStatus | status | Відображає статус номера |
| BookingPage | room | Відображає секцію підготовки бронювання |
| BookingFormPreview | idPrefix, roomName | Відображає макет форми бронювання |
| FormField | id, label, hint, children | Формує поле форми з підписом і підказкою |
| AppButton | children, type, variant, disabled | Повторно використовувана кнопка |

## Основні рішення

Компоненти було розділено за відповідальністю. Сторінкові компоненти поєднують дані та окремі блоки інтерфейсу, а предметні компоненти відповідають за відображення інформації про номери.

Компонент Section використовується повторно для різних секцій і отримує вкладений вміст через children.

Компонент RoomStatus використовується в різних частинах застосунку, що дозволяє не дублювати правило відображення статусу номера.

Для оформлення застосунку використовуються власні CSS-стилі без підключення React Bootstrap.
