# Веб-сайт готельного комплексу

## Тема
Розробка веб-сайту готельного комплексу.

## Проблема
Користувачам необхідно мати зручний спосіб отримання інформації про готельний комплекс, доступні номери, їх характеристики, вартість, послуги та контактні дані.

## Користувачі
Основними користувачами вебзастосунку є потенційні гості готельного комплексу.

## Основні сутності
- готельний комплекс;
- номери;
- категорії номерів;
- послуги;
- ціни;
- фотографії;
- контактна інформація.

## Основні сценарії
- перегляд інформації про готельний комплекс;
- перегляд доступних номерів;
- перегляд характеристик і вартості номерів;
- перегляд послуг;
- перегляд контактної інформації.

## Основні сторінки
- Головна;
- Номери;
- Послуги;
- Про готель;
- Контакти.

## Реалізовано 1.1
У першій лабораторній роботі створено основу ReactJS-проєкту та підготовлено початкову структуру вебзастосунку.

## Заплановано
У наступних лабораторних роботах планується реалізувати компоненти інтерфейсу, навігацію між сторінками, роботу з даними, форми та інші інтерактивні функції.

## Реалізовано 1.2

У лабораторній роботі 1.1 створено початковий ReactJS-застосунок веб-сайту готельного комплексу з відображенням номерів.

У лабораторній роботі 1.2 виконано компонентний рефакторинг застосунку. Створено спільне компонування, навігацію, повторно використовувані секції, список і картку номера, компонент статусу, спільні елементи форми та макет секції підготовки бронювання.

Збережено початковий сценарій перегляду номерів готельного комплексу.

## Заплановано

У наступних лабораторних роботах планується реалізувати інтерактивний вибір номера, керування станом компонентів, фільтрацію номерів, повноцінну форму бронювання, маршрутизацію між сторінками та подальшу роботу з даними.

## Лабораторна робота 2.1

У застосунку реалізовано керування станом і взаємодію між компонентами React:

- локальний стан розгортання деталей номера;
- керовані фільтри пошуку та доступності;
- вибір номера зі спільним станом;
- керовану форму підготовки бронювання;
- синхронний підсумок введених даних;
- useEffect для зміни заголовка вкладки браузера;
- власний хук useRoomFilters;
- Context API для стану вибраного номера;
- окремі контейнерні компоненти для каталогу та бронювання.

## Лабораторна робота 2.2. План маршрутизації

| Шлях | Компонент | Параметри | Джерело даних | Поведінка за відсутності даних |
|---|---|---|---|---|
| `/` | HomePage | Немає | Статичний опис готелю | Відображається головна сторінка |
| `/rooms` | RoomsPage | `q`, `available` | `src/data/rooms.js` | Відображається повідомлення про відсутність результатів |
| `/rooms/:roomId` | RoomDetailsPage | `roomId` | `src/data/rooms.js` | Повідомлення про відсутній номер і посилання до каталогу |
| `/bookings` | BookingsPage | Немає | Демонстраційний список бронювань | Повідомлення про відсутність бронювань |
| `/bookings/new` | BookingCreatePage | `roomId` у рядку запиту | `src/data/rooms.js` | Якщо номер не вибрано або його не знайдено, пропонується перейти до каталогу |
| `/bookings/:bookingId/edit` | BookingEditPage | `bookingId` | Демонстраційний масив бронювань | Повідомлення про відсутнє бронювання |
| `*` | NotFoundPage | Невідомий шлях | Не потрібне | Повідомлення про невідому сторінку та посилання на головну |

### Відновлення стану

- Пошук і фільтр доступності відновлюються з параметрів URL.
- Ідентифікатор номера визначається з адреси сторінки або параметра `roomId`.
- Чернетка форми бронювання зберігається лише в локальному стані React.
- Тимчасовий вибір номера через Context API не зберігається після перезавантаження.
- Демонстраційні бронювання зберігаються в локальному масиві даних.

### План реалізації

1. Підключити React Router.
2. Створити спільний макет із Outlet і навігацією.
3. Розділити головну сторінку та каталог номерів.
4. Реалізувати сторінку деталей номера.
5. Перенести фільтри в параметри URL.
6. Створити вкладений розділ бронювань.
7. Реалізувати сторінки створення та редагування бронювання.
8. Додати оброблення невідомих маршрутів і відсутніх записів.
9. Перевірити переходи та production-збірку.
